# FocusGate — 墨色专注

Android 数字自律工具，支持抖音、Bilibili、小红书的普通全屏前台使用管理。当前版本：`0.4.1-trial`，仍为试用版。

## 安装

从 [GitHub Releases](https://github.com/IcyCongee/FocusGate/releases) 下载 APK。升级时直接覆盖安装，不要卸载旧版，以保留应用绑定、配置及记录。

打开「设置」，按引导启用无障碍服务和使用情况访问权限。分别核实目标应用的包名绑定，再开启对应限制。无需普通悬浮窗权限。

## 使用规则

- 抖音、Bilibili、小红书各自独立管理，可分别开启、关闭或暂停限制。
- 开始使用前填写理由并主动选择时长，单次实际批准最多30分钟。
- 只累计获准的前台使用时间；息屏、锁屏和切换应用后暂停倒计时。
- 离开不超过10分钟保留本次时段。返回时显示剩余时间，点击「继续」才恢复计时。
- 刚好10分钟仍可继续；超过10分钟结束旧时段，需要重新填写理由和时长。
- 等待确认或再次切走不会重置原离开期限。主动离开导致时段结束不触发冷却。
- 用完批准时间后退出目标应用，进入该应用独立的10分钟冷却。
- 服务断连、重连或进程恢复后结束旧时段，不恢复旧许可。

「暂停限制」会取消该应用的拦截，但继续记录可确认的前台用量；恢复限制后需重新填写理由。「关闭」会结束该应用的时段并停止后续管理和记账。两者均保留已有用量与冷却。

## 界面与数据

采用深色主题，提供首页、记录和设置。首页显示所选应用的剩余时间或冷却状态，记录页展示最近结束的使用时段。

数据保存在设备本地，无网络权限、无分析 SDK，禁用系统备份。诊断日志不包含用户填写的使用理由，但包含应用包名、时间和窗口状态，请自行保管；可在「设置 → 权限与运行状态 / 导出日志」手动导出。

只管理普通全屏前台使用，不管理后台音频、投屏、小窗或画中画。尚未提供每日额度、延长、规则编辑、系统历史导入和完整统计；用量数字标记为「已记录、不完整」。

## 构建与验证

需要 JDK 17 和 Android SDK。项目使用 Gradle 8.9、AGP 8.7.3、Kotlin 2.0.21、Android Platform / Build Tools 35，最低 Android 11（API 30），目标 Android 15（API 35）。

PowerShell：

```powershell
.\tools\dev.ps1 doctor
.\tools\dev.ps1 build -ToolArgs @('--no-daemon')
.\tools\dev.ps1 test -ToolArgs @('--no-daemon')
```

可通过 `-JdkHome` 和 `-SdkRoot` 指定工具目录；脚本也会查找本机 JDK 和 `.tools/sdk`。工具、缓存及构建输出不纳入 Git。

生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`，使用本机调试签名。当前功能已通过37项 JVM 单元测试和 Android Lint；息屏解锁、原生界面及系统交互仍需真机验证。
